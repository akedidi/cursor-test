BNS Welcome Kit Delivery Flow
Purpose

This page describes the current understanding of the BNS Welcome Kit delivery flow.

Flow overview

Insert workflow diagram here

The BNS Sales API creates the policy in EIS.
Customer documents are uploaded and referenced in Sugar.
Sugar Connector sends the Upload Notification API call to EIS DXP Gateway.
EIS processes the DocGen event and prepares the document and email payload.
For BNS, the Welcome Kit contains:
one static document retrieved from IBM COS using static_file_uuid;
one document retrieved from Sugar using sugar_document.
Both documents are added to the Welcome Kit email payload.
MDirector sends the email to the customer.
The delivery status is returned to EIS/BAM.
Document retrieval logic
static_file_uuid → document retrieved from IBM COS.
sugar_document → document retrieved from Sugar.
Neither property → document generated by Cardif PDF Generator.
